# Screenshots for the main README

Drop PNGs with the exact filenames below and they'll light up the gallery in `/README.md`.

| Filename | What it should show | Suggested size |
|---|---|---|
| `web-map.png` | Public map on web — fire pins, raw sightings toggle, weather widget, nav bar | 1600 × 900 |
| `mission-control.png` | Fireman role — Mission Control sidebar open with zones / lines / water / propagation | 1600 × 900 |
| `mobile-map.png` | Mobile map screen with pins and FAB | 1080 × 2340 |
| `mobile-calibrate.png` | GPS + compass calibration gate | 1080 × 2340 |
| `mobile-capture.png` | Camera viewfinder with bearing / GPS HUD | 1080 × 2340 |
| `mobile-confirm.png` | Confirm screen with YOLO detection boxes on the preview | 1080 × 2340 |

Tips:

- For web shots, use a 1600 × 900 window so the gallery stays visually consistent.
- For mobile shots, iOS Simulator / Android Studio emulator at a Pixel-6-sized device works well.
- PNG preferred over JPG (preserves UI sharpness); keep each file under ~500 KB with `pngquant` or `oxipng` if needed.
